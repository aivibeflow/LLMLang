# Shared cross-direction prototypes

These two integrated prototype families serve multiple research directions. They retain stable paths to avoid duplicating implementations or splitting coupled evidence and tests. Dedicated prototypes are located under their thematic direction instead.

- [Dependency Graph](DEPENDENCY-GRAPH-01/README.md) — semantic representation, formal verification, compiler lowering, and toolchain integration. See [Lean/Logos](DEPENDENCY-GRAPH-01/logos_binding/).
- [RT-04-01](RT-04-01/) — language semantics, effects, ownership, runtime and cross-profile evidence.

See the [research direction index](../README.md#research-directory-layout).
