## Research outcome

The preferred primary checker candidate is Logos, pinned for research to:
- Logos: `cf18742973861b3718d04c5f25775448098ff474`;
- cvc5 release: `cvc5-1.4.2`, commit `282d5e0c84baf49c780704c532f87ba66d8b513d`;
- Lean: `leanprover/lean4:v4.34.0`;
- Mathlib: `v4.34.0`.

This pair is a candidate only. Compatibility is not established until a golden CPC proof is generated by that cvc5 build and accepted by that Logos build.

The central integration requirement is an in-Lean wrapper that compares the assumptions parsed from a CPC proof with the exact expected assumption AST produced from the canonical LLMLang Relational Query IR. The wrapper must have a Lean theorem showing that a successful verdict proves the expected formula unsatisfiable.

The initial proof profile is restricted to QF_LIA. The current symbolic encoder cannot be reused unchanged because it accepts nonlinear multiplication, strings, and `set-logic ALL`.

## Acceptance gate for implementation

The next implementation must not issue `PROVEN_INDEPENDENCE` until:
1. the exact assumptions are bound in Lean;
2. the checker returns `correct`;
3. the full pinned Logos proof build is validated;
4. the QF_LIA profile is enforced and its correspondence to SMT-LIB semantics is proved in Lean;
5. the LLMLang relational query and encoder correspondence is proven.

Until then, solver answers remain `SOLVER_REPORTED_UNSAT` or `UNKNOWN`.
